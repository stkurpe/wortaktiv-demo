# WortAktiv interactive prototype

Статический интерактивный прототип браузерного приложения для изучения немецкой лексики в контексте.

## Что можно попробовать

- кликнуть по подсвеченному выражению или выделить фрагмент статьи;
- посмотреть словарно-контекстный разбор;
- переключить лицевую и обратную сторону карточки;
- отредактировать текст обеих сторон карточки и сохранить изменения локально;
- вернуть исходное содержимое карточки;
- открыть текущее выражение в немецком Wiktionary на этапе «Понять»;
- переключить базовый язык между русским, английским и немецким: вместе с интерфейсом меняются значения, переводы, примеры и задания карточек;
- прослушать выражение и предложение системным немецким голосом;
- пройти имитацию поиска лицензированной OGG-записи, проверить источник и явно прикрепить её к карточке;
- имитировать сохранение в Anki;
- выполнить упражнение и получить обратную связь;
- сохранить повторную встречу;
- открыть статистику по дням и учебным единицам;
- сортировать самые сложные выражения по сложности, времени и ошибкам;
- скачать всю локальную статистику в JSON или получить оформленный PDF-отчёт.

Данные сохраняются только в `localStorage` браузера. Настоящие словари, Wikimedia API, AI и AnkiConnect в прототипе не вызываются: сетевой поиск аудио и его надёжная доставка реализованы в production fork, а здесь воспроизводится тот же пользовательский процесс без внешних запросов.

## Локальный запуск

Откройте `index.html` напрямую или запустите любой статический HTTP-сервер в этой папке.

## GitHub Pages

GitHub Pages публикует статические файлы непосредственно из корня ветки `main`.
